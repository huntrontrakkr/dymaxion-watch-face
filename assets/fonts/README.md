# Typography references

These are existing typefaces, credited to their designers. They are not original
Dymaxion font designs. Unmodified upstream files and their licenses are retained
here so bitmap proofs and watch resources can be reproduced.

| Reference | Source | Study use |
| --- | --- | --- |
| Alegreya Sans Medium | [Huerta Tipográfica](https://github.com/huertatipografica/Alegreya-Sans), distributed by [Google Fonts](https://github.com/google/fonts/tree/main/ofl/alegreyasans) | Calligraphic proportions and four figure sets |
| Fira Sans Medium | [Carrois / Edenspiekermann](https://carrois.com/fira/), distributed by [Google Fonts](https://github.com/google/fonts/tree/main/ofl/firasans) | Instrument clarity; lining and oldstyle comparisons |
| Recursive 1.085 | [ArrowType](https://github.com/arrowtype/recursive/tree/main/fonts/ArrowType-Recursive-1.085) | Sans instance: MONO 0, CASL .35, weight 500, slant 0, CRSV 0 |

Downloaded 2026-09-22. Each family is licensed under SIL OFL 1.1; see its folder.
Recursive has no oldstyle figure set. The study explicitly keeps its lining
numerals when that comparison is selected.

`tools/prepare-watch-type.py` selects numeral glyphs through the fonts' own
OpenType substitutions and bakes those mappings for Pebble. Glyph outlines
are not mixed between families or redrawn. Prepared subset family names include
"Watch" and the figure role to distinguish them from upstream installations.

The watch uses the original Dymaxion Span clock and Draft information lettering,
generated by `tools/generate-draft.py`. No reference font is opened by that
generator. Span and Draft are Apache-2.0, as is the project; these reference
families retain their separate OFL licenses and authorship.
