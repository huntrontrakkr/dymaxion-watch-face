# Dymaxion 0.5.3

This update makes the main clock cheaper to draw, especially during its minute
animation. Each frame now uses a single bitmap draw in place of hundreds of
individual lines, preserving the same pixel-perfect figures and 400 ms flip.

Two default-clock benchmarks used 89–91% fewer instructions, including Pebble's
graphics firmware. All eight numeral styles, custom colors, moving layouts and
Quick View were checked. The change adds only 36 bytes of heap memory, and the
previous renderer remains available if the bitmap cannot be allocated.

These measurements describe clock-drawing work. Actual battery-life gains still
need physical-device measurement.
